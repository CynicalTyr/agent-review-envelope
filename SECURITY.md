# Security

- Never open issues that paste live API keys, cookies, or `.env` values.
- This project is a **library**, not a hosted messenger.
- If you find a way a review envelope can be bypassed so a worker pages a
  human without the second process, file a private advisory if the GitHub
  repo has them enabled; otherwise an issue with a **redacted** repro.

Do not ask maintainers to add a send-chat MCP tool “just for debugging.”
That is dual-control collapsing on purpose.
